# Exploratory-Data-Analytics-Lab-Assignments
# Data Analytics Lab Assignments

## About This Repository

This repository contains my Data Analytics Lab assignments completed using Python in Jupyter Notebook as part of my B.Tech Computer Science and Engineering program, specializing in Data Science.

The assignments cover essential data analytics techniques, including data manipulation, data cleaning, visualization, statistical analysis, time series analysis, clustering, and dimensionality reduction.

## Objectives

- Understand and apply data analytics concepts using Python.
- Perform data cleaning and preprocessing.
- Explore datasets using statistical methods.
- Create visualizations to identify patterns and trends.
- Apply analytical and machine learning techniques to datasets.
- Interpret data and present meaningful insights.

## Technologies Used

- **Programming Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, SciPy, Scikit-learn, Statsmodels
- **Data Analysis Techniques:** Data Cleaning, Exploratory Data Analysis (EDA), Statistical Analysis, Data Visualization, Clustering, PCA

## Assignments Included

### Assessment 1: Data Manipulation
Working with DataFrames, combining datasets, merging, joining, and data normalization techniques.

### Assessment 2: Data Import and Exploration
Importing datasets, inspecting data, handling basic data operations, and calculating descriptive statistics.

### Assessment 3: Data Cleaning and Univariate Analysis
Identifying missing values and duplicates, handling outliers, and analyzing individual variables using statistical summaries and visualizations.

### Assessment 4: Bivariate Analysis
Studying relationships between two variables using scatter plots, bar charts, box plots, violin plots, and correlation analysis.

### Assessment 5: Multivariate Analysis
Exploring relationships among multiple variables using scatter plots, pair plots, faceted visualizations, and parallel coordinate plots.

### Assessment 6: Time Series Analysis
Analyzing time-dependent data, identifying trends and seasonality, performing time series decomposition, and generating forecasts.

### Assessment 7: One-Dimensional, Two-Dimensional, and N-Dimensional Analysis
Applying descriptive statistics, frequency distributions, cross-tabulation, grouped analysis, and multivariable visualization techniques.

### Assessment 8: K-Means and Hierarchical Clustering
Applying clustering algorithms, scaling numerical features, using the elbow method, and visualizing hierarchical clusters with dendrograms.

### Assessment 9: Principal Component Analysis (PCA)
Standardizing numerical data, reducing dimensionality, analyzing explained variance, and visualizing principal components.

## Learning Outcomes

Through these assignments, I gained practical experience in:

- Data manipulation and preprocessing using Pandas and NumPy.
- Statistical analysis and exploratory data analysis.
- Creating meaningful visualizations using Matplotlib and Seaborn.
- Understanding relationships between variables.
- Analyzing time series data and forecasting.
- Applying unsupervised learning techniques such as K-Means and hierarchical clustering.
- Using PCA for dimensionality reduction.
